# Learning Hub

One topic a week, seven short interactive modules (about 20 minutes a day), an archive of past weeks, and a weekly check-in that shapes the next one.

- **This week**: the current week's seven days.
- **Archive**: every past week, reopenable.
- **Me**: how the hub teaches you, the weekly check-in (opens a prefilled GitHub issue), and a backup code to move progress between devices.

Static site, no build step. Open `index.html` through any web server, or use GitHub Pages (Settings, Pages, deploy from `main`, root).

Progress and feedback are stored in your browser (`localStorage`). Content lives in `weeks/`. See `CLAUDE.md` for how new weeks are added.
